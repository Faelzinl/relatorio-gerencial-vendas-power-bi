# Criando um Relatório Gerencial de Vendas com Power BI

Projeto desenvolvido durante o bootcamp de Power BI, com o objetivo de criar um relatório gerencial de vendas utilizando o Microsoft Power BI.

## Sobre o projeto

O relatório utiliza dados financeiros para apresentar informações de vendas de forma visual e interativa, permitindo uma análise mais fácil dos principais indicadores.

Durante o desenvolvimento foram utilizados recursos como:

- Gráficos e indicadores
- Segmentadores de dados (slicers)
- Botões de navegação
- Indicadores (bookmarks)
- Visuais alternativos
- Interações entre páginas
- Layout personalizado

## Ferramenta utilizada

- Microsoft Power BI Desktop

## Dados

O projeto foi desenvolvido utilizando a base de dados financeira disponibilizada no desafio do bootcamp.

## Objetivo

Criar um relatório gerencial de vendas com uma apresentação visual organizada e recursos de interação para facilitar a análise dos dados.

## Arquivos

O arquivo `.pbix` contém o relatório desenvolvido no Power BI.
